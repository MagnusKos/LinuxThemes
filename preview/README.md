# Preview

Here you can see a bunch of screenshots and generated color palettes.

## Screenshot names descriptions

- **ThemeName1_MM.YY.png**: Kate text editor as an example window,
focus on the top-most part of the window. *Breeze* selected both as a
window decorator and as a application style;

- **ThemeName2_MM.YY.png**: Plasma settings window. *Breeze* selected both as a
window decorator and as a application style;

- **ThemeName3_MM.YY.png**: Dolphin file manager as an example window,
focus on the top-most part of the window. *Klassy* selected both as a
window decorator and as a application style.


## More notes

You can see that combination of Klassy and non-modified themes
causes "glueing" of window header and container right under it
(sometimes there is a menu bar, so you understand what I mean).
And I really don't like it at all, so that is the main reason
why I decided to rework a bit already existing (in multiple instances) Plasma's color-schemes.
